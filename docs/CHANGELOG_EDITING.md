# 更新日志维护

编辑 `public/changelog.json`，按从新到旧排列。每条记录包含 `title`（标题）、可选 `date`（日期）和 `body`（正文条目数组）。正文支持换行，按纯文本显示；不需要 HTML。

```json
[
  {
    "title": "在这里填写更新标题",
    "date": "2026-10-14",
    "body": ["第一条更新说明", "第二条更新说明\n可以继续补充详细内容"]
  }
]
```

允许很多条更新和长正文，网站弹窗内可滚动阅读。空数组表示暂未发布更新日志。修改后重新构建、部署；也可以单独替换网站根目录中的 `changelog.json`。编辑器打开日志时会重新读取该文件。
