# 更新日志维护

编辑 `dist/changelog.json`，按从新到旧排列。每条记录包含 `title`（标题）、可选 `date`（日期）和 `body`（正文条目数组）。正文支持换行，按纯文本显示；不需要 HTML。

```json
[
  {
    "title": "在这里填写更新标题",
    "date": "2026-10-14",
    "body": ["第一条更新说明", "第二条更新说明\n可以继续补充详细内容"]
  }
]
```

允许很多条更新和长正文，网站弹窗内可滚动阅读。空数组表示暂未发布更新日志。以后直接修改 `dist/changelog.json`，然后上传整个 `dist` 即可，无需为了更新日志重新构建。运行 `npm run build` 时会保留这份日志，同时正常清理和重新生成其他构建文件。开发预览也读取同一份文件。该日志文件单独纳入 Git，其他构建产物仍被忽略。请勿手动删除整个 `dist` 文件夹；这份日志就是唯一维护源文件。编辑器打开日志时会重新读取该文件。
