# 灯光轨道映射与校准

这是本地谱面数据的推定映射，尚未经过游戏实机或官方枚举代码校准。2026-10-12 检查的 603 份 Event 文件中，type 2 和 4 的事件数分别为 159,563 和 160,408，且主要取值分布高度相似；type 1 常用于开场，type 6 密集随拍出现，type 7 / 9 常在场景交接处变化。结合用户提供的十轨说明，采用以下默认表。

| 编辑器名称 | 默认 type | 参数 |
| --- | --- | --- |
| 左侧灯光速度 | 3 | 0–6 |
| 左侧灯光 | 2 | 灯光值 |
| 右侧灯光 | 4 | 灯光值 |
| 右侧灯光速度 | 5 | 0–6 |
| 主灯光 | 1 | 灯光值 |
| 律动光 | 6 | 灯光值 |
| 菱形灯光 | 7 | 灯光值 |
| 菱形灯光速度 | 8 | 0–6 |
| 星空灯光 | 9 | 灯光值 |
| 星空灯光速度 | 10 | 0–6 |

左右方向、速度枚举和具体灯光值的官方含义无法从 YAML 单独证明，尤其旧谱的 type 3 包含 value 7，不能视为已经确认的 0–6 速度枚举。编辑器不丢弃或钳制原始值，选择此类事件时会显示“原值 7”。type 0、12、13、101 等未映射类型在附加的扩展轨道中显示，仍可选择、修改、保存。未来发现其他类型同样保留并显示。

“轨道映射”允许为十条轨道指定不重复的原始 type，配置保存于当前浏览器，不改变任何旧事件，也不向游戏谱包添加私有字段。恢复默认映射只影响标签。

灯光值暂按以下方案编辑：0 绿色关闭、1 绿色亮起、2 绿色渐入／闪烁、3 绿色渐出；4 黄色关闭、5 黄色亮起、6 黄色渐入／闪烁、7 黄色渐出。场景内提供左右扫光、主灯边框、律动边线、菱形和星点的示意预览；渐变以节拍驱动，速度影响扫动和旋转。此预览用于辅助编排，不声称复现游戏中的材质、亮度或准确的动画持续时间。

## 操作

按 3 切换灯光模式，点击“灯光总览”将相机定位到右侧轨道。轨道与音符共用当前拍数、SNAP、纵深和预览范围：

- 点击空位，在该轨对应的拍数添加当前所选参数的事件；新事件默认不选中。
- 绿／黄短条表示灯光事件；速度用绿点和半透明绿色高度柱表示，0 静止，6 最快。
- 点击已有事件可编辑节拍、轨道和参数；Alt 拖动同时移动节拍和轨道。
- Del 悬停删除，复制粘贴、撤销重做及 Ctrl+A 视野内选择与音符共用。
- 未识别原值和扩展字段沿用现有 YAML 读写，不自动“纠正”。
