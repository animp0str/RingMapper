# RingMapper

闪韵灵境本地谱面编辑器。从项目 `Map/` 中读取歌曲，支持原生 YAML 谱面编辑与 ZIP 导入导出。

## 启动

需要 Node.js 22.12+（当前开发验证使用 Node.js 24）。在项目目录执行：

```powershell
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。也可双击 `启动编辑器.cmd`，保持服务终端运行。

生产构建及本地预览：

```powershell
npm run build
npm run preview
```

预览地址为 `http://127.0.0.1:4173`。本项目使用本地 API 读取和保存 Map，需要通过以上服务运行，不能直接双击 `dist/index.html`。

## 音符对应关系

按用户最终更正后的定义：

| YAML 数组 | 含义 | 编辑区域 |
| --- | --- | --- |
| `notes` | 手部音符 | 上方 10 段圆环；使用 4 列 × 3 层网格的外圈 |
| `ringNotes` | 脚部音符 | 下方平台；保留 0–35 的位置编号 |
| `obstacles` | 障碍物 | 独立轨道与预览区域 |
| `events` | 灯光 / 场景事件 | 独立事件文件与按类型分轨的时间轴 |

圆环只有 **10 个有效位置**：4 列 × 3 层网格的外圈，中间层的 `(1,1)` 与 `(2,1)` 不使用。全库手部音符也仅出现在这 10 个位置。预览、时间轴、放置和校验共用同一位置表。

空间预览使用 **Three.js / WebGL 2 真正的 3D 场景**：透视相机、半透明的 10 段圆环、与圆环分区同形的立体弧形手部音符、脚部音符与长音符、障碍物、纵深轨道和分组连线。手部音符不显示方向箭头，原始方向字段仍可编辑并保留。红蓝音符使用更厚的实体与高饱和颜色；3D 选中项保留原色，画布不显示焦点白框，选中状态可在属性面板和时间轴查看。拾取通过三维射线检测，旋转和缩放后仍能编辑。点击场景左上方视图设置可调整圆环起始角度、顺逆时针、不透明度（默认 22%，范围 5%–60%）和显示未来 4 / 8 / 16 拍。

脚部音符按参考图显示为宽而低的踏板：宽度约为底部放置区域的 45%，长音符为同宽的半透明延伸带。0–35 仍是位置编号，踏板外形尺寸独立于编号间距；点击踏板边缘也可选中、拖动或悬停删除。

场景左上角“纵深拉伸”滑杆可在 **0.25×–3×** 范围调整每拍的空间距离，音符、长音符、障碍物、拍线和拍号同步伸缩，不改变谱面时间与 BPM。地面拍线旁显示实际节拍编号，数字朝向相机以方便阅读，每 4 拍强调一次。

## 已实现

- 自动扫描本地曲库、封面、音频及实际存在的难度文件；兼容新旧两套元数据命名及 GBK / UTF-8 编码。
- 新建谱面、导入 ZIP 或 YAML、导入音频、封面居中裁剪为 512 × 512 PNG。
- 手部方向 / 颜色 / 地雷、脚部短音符 / 长音符、障碍物、事件属性编辑；阻止放置到两处未使用的内部格。
- 右侧全屏 3D 工作区；歌曲与难度集中在左栏，歌曲信息、工具、时间轴及播放控制作为场景内的子窗口。
- 编辑工具可拖动、收起，双击标题栏复位；底部时间轴默认收起，可向上展开、向下隐藏；展开时占用下方空间并缩小 3D 画布，相机比例和拾取同步更新。
- 真正的 3D 空间预览、自由旋转、WASD 平移、按住右键时 Shift / 空格垂直移动、相机远近按钮、正面 / 透视 / 俯视相机及一键重置。
- 时间轴吸附（1 拍至 1/32 拍）、缩放、滚动、拖动、框选、多选、按拍数范围选择与删除。
- 撤销重做、复制粘贴、左右／上下／对角镜像；手部同色音符打组、取消组，复制时生成新的分组 ID。
- 音频同步播放、波形、播放速度和音量、循环区间、节拍器、手动点击测 BPM、BPM 和音频偏移设置。
- 歌曲与谱师信息、难度创建、跨难度复制灯光、手脚跳跃速度与出生偏移、书签。
- 字段 / 分组 / 同拍同位置检查，音符数量、平均密度、红蓝比例和层级统计。
- 本地保存、ZIP 导出所有已有难度和歌曲资源；保留未知字段、分组与 `customData`。
- 保存前备份到 `.ringmapper-backups/<歌曲目录>/<时间戳>/`，当前 Info / 谱面 / 事件文件的外部修改检测；写入失败回滚已写入的文件。
- 浏览器草稿恢复。草稿只保存 YAML 数据；尚未保存的外部音频和封面需要重新导入。

## 基本操作

1. 从左侧选择歌曲和难度，或点击“新建”/“导入”。新建歌曲可在设置中选择音频和封面。
2. 使用底部进度条、节拍输入框或 3D 内的滚轮定位。直接点击圆环分区或脚部平台即可放置对应音符，无需切换工具；点击已有的同拍音符可选中它。时间轴仍使用“放置”工具。新增音符默认不选中。**按住 Shift 时禁止新增**，包括 3D、时间轴、放置工具与添加按钮；Shift 多选和右键＋Shift 降低相机仍可使用。
3. 点击音符后在悬浮编辑工具中调整属性；与圆环重叠的已有音符可用 Alt＋点击直接选中。3D 内按住 Alt＋左键拖动音符，可在对应的手部或脚部轨道内换位，并吸附到合法位置；保持原节拍、颜色、方向、分组和时长，整段拖动可一次撤销。开始拖动时暂停播放。时间轴中拖动可移动节拍和位置；空白处拖动可框选。
4. 在时间轴中，`Alt` 拖动手部音符更改方向；`Alt` 拖动脚部音符或障碍物修改持续时间。
5. 选取多个同色手部音符后点击“打组”。组头标记为 `1`，组尾标记为 `2`，其余组员保留同一个 `groupId`。
6. 镜像方式在工具窗口选择，再点击镜像按钮应用于选中项。“上下”仅翻转手部层级及击打方向；“对角”按上下、左右同时翻转。左右／对角同时互换红蓝，并反转脚部位置及障碍物位置；上下不移动脚部与障碍物。所有方式保留节拍、时长、分组和扩展字段，可撤销。
7. 播放试听并运行“检查谱面”，再保存或导出 ZIP。

常用快捷键：`Space` 播放，`V / B / E` 选择 / 放置 / 擦除，`Ctrl+Z / Y` 撤销 / 重做，`Ctrl+C / V` 复制 / 粘贴，`Ctrl+S` 保存，`Delete` 删除鼠标指向的音符（支持 3D 和时间轴，无需先选中），`Q` 切换当前放置颜色，左右箭头逐拍移动，`Shift+点击` 多选，中键换色，时间轴右键删除。

鼠标在画布空白处时，Delete 不会误删其他选中项；鼠标在画布外时保留删除选中项的行为。Q 不修改已有音符，也不会拦截输入框中的正常录入。3D 左上角的红／蓝按钮始终显示当前放置颜色，也可点击切换。

3D 视图：**右键拖动旋转**；**滚轮向下前进、向上后退歌曲进度**，移动幅度随时间轴的吸附细分调整，播放中也能定位。点击预览使其获得焦点后用 **WASD 水平移动相机**。**按住鼠标右键时，Shift 降低、空格升高**；松开右键后空格播放 / 暂停，Ctrl 仅用于编辑快捷键。左上方的 **＋ / −** 按钮拉近 / 拉远相机，视角菜单选择正面 / 透视 / 俯视，定位按钮重置视角。预览中的右键用于控制相机；删除音符可使用擦除工具或 Delete。场景不显示圆环及脚部位置编号，精确字段仍在属性面板和时间轴中查看。

相机下拉栏、工具按钮等操作结束后，键盘焦点会回到 3D 编辑区，空格可直接播放 / 暂停，音符选中状态不会因相机或面板操作丢失。输入框仍可正常录入；在编辑区输入框中按 Enter 可结束录入并回到编辑区。

## 格式与兼容边界

详见 [谱面格式说明](docs/MAP_FORMAT.md)。

- 时间字段以拍为单位；编辑器使用 `音频秒数 = 拍 × 60 / BPM + songTimeOffset`，偏移符号需在游戏中试听对照。
- 支持保留原字段值和未知扩展，写出时按节拍排序。YAML 注释、缩进、字段引号形式不保证保持；保存统一使用 UTF-8。
- 原始灯光事件可以编辑、复制、保存，预览只显示事件触发。未凭视频口述猜测 `type/value` 的具体官方效果。
- 3D 预览需要 WebGL 2；浏览器不支持时会明确提示，时间轴仍可编辑。圆环精确角度、脚部编号与障碍物类型的游戏空间语义仍可进一步校准。
- 未接入官方账号 / 云曲库、自动 BPM 检测、官方灯光场景渲染或音频转码。点击测 BPM 是人工辅助工具。
- 浏览器可预览 OGG / MP3 / WAV；参考视频要求游戏使用 OGG，本工具不会把 MP3 / WAV 自动转换为 OGG。
- 音符坐标、脚部位置编号的实际空间含义、障碍物类型语义和游戏端运行兼容性仍需实机验证。
- 目前使用固定 BPM。现有样本中的 `customData.BPMChanges` 均为空；非空变速数据会保留，但不会参与播放时间换算。

## 验证

```powershell
npm test
npm run test:ui
npm run build
```

核心测试覆盖时间换算、历史记录、路径边界、圆环映射、新旧元数据、原始 YAML 的语义往返以及全库谱面校验。浏览器测试覆盖真实编辑、播放、ZIP 导入导出、本地资源保存、备份、冲突检测与难度创建，以及 WebGL 渲染、全部 10 个位置拾取、滚轮定位与相机控制、浮动面板与收起时间轴、半透明圆环与无箭头弧形音符、播放纵深变化和脚部长音符，以及直接放置、默认未选中、焦点返回、Alt 拖动与撤销、Shift 放置保护、Q 换色、悬停删除、纵深拉伸、地面拍号和三种镜像。

浏览器测试默认使用已安装的 Chrome；若使用 Playwright 自带 Chromium，可设置 `PLAYWRIGHT_CHANNEL=chromium` 并运行 `npx playwright install chromium`。全库 YAML 往返检查需要约 2–3 分钟。

测试创建的歌曲目录使用独立的 `ringmapper-test-*` 前缀并在结束后清理，不修改原始歌曲。
