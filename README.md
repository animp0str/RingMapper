# RingMapper

可部署为静态网站的谱面编辑器。用户在浏览器中选择自己的本地 Map 文件夹，读取和保存原生 YAML 谱面；音乐、封面和谱面不上传。支持 ZIP／RAR 导入、ZIP 导出；自带 Diabolic Swing 示例谱面，可试听、编辑和另存。

桌面 Chrome / Edge 支持目录读写；其他浏览器可使用 ZIP。第一次打开时点击 **打开本地文件夹**，选择包含歌曲子目录的 Map，按提示授权。

## 启动

需要 Node.js 22.12+（当前开发验证使用 Node.js 24）。在项目目录执行：

```powershell
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。也可双击 `启动编辑器.cmd`，保持服务终端运行。

生产构建及本地预览：

```powershell
npm run build
npm run preview
```

预览地址为 `http://127.0.0.1:4173`。开发与预览均不依赖本地文件 API。构建产物可放在任意 HTTPS 静态网站托管服务上；不能直接双击 `dist/index.html` 使用目录授权。发布步骤见 [网站部署说明](docs/DEPLOYMENT.md)。

## 音符对应关系

按用户最终更正后的定义：

| YAML 数组 | 含义 | 编辑区域 |
| --- | --- | --- |
| `notes` | 手部音符 | 上方 10 段圆环；使用 4 列 × 3 层网格的外圈 |
| `ringNotes` | 脚部音符 | 下方平台；保留 0–35 的位置编号 |
| `obstacles` | 障碍物 | 独立轨道与预览区域 |
| `events` | 灯光 / 场景事件 | 独立事件文件与按类型分轨的时间轴 |

圆环只有 **10 个有效位置**：4 列 × 3 层网格的外圈，中间层的 `(1,1)` 与 `(2,1)` 不使用。全库手部音符也仅出现在这 10 个位置。预览、时间轴、放置和校验共用同一位置表。

空间预览使用 **Three.js / WebGL 2 真正的 3D 场景**：透视相机、半透明的 10 段圆环、与圆环分区同形的立体弧形手部音符、脚部音符与长音符、障碍物、纵深轨道和分组连线。手部音符不显示方向箭头，原始方向字段仍可编辑并保留。红蓝音符使用更厚的实体与高饱和颜色；3D 选中项保留原色，并显示青色轮廓和勾选标记，画布不显示焦点白框。拾取通过三维射线检测，旋转和缩放后仍能编辑。“设置”中的滑杆调整圆环不透明度（默认 22%，范围 0%–100%）；相机重置保持居中，并在原来的俯看角度上向下增加 10°。预览范围已移到场景外侧，与纵深拉伸并列显示，可用滑杆连续调节未来 1–64 拍。

脚部音符按参考图显示为宽而低的踏板：宽度约为底部放置区域的 45%，长音符为同宽的半透明延伸带。踏板上方显示始终朝向相机的 **-18…-1、1…18** 轨道数字，不显示 0；远处过小和相互重叠的文字隐藏，优先显示选中项，避免密集文字堆叠；原始文件中的 0–35 仍是位置编号，踏板外形尺寸独立于编号间距；点击踏板边缘也可选中、拖动或悬停删除。

场景左上角“纵深拉伸”滑杆可在 **0.25×–10×**（默认 **5×**） 范围调整每拍的空间距离，音符、长音符、障碍物、拍线和拍号同步伸缩，不改变谱面时间与 BPM。时间轴缩放与此数值联动（1× 对应 48 像素/拍），不再显示独立缩放条；Ctrl＋滚轮用于逐级切换 SNAP 预设。地面细分导线随 SNAP 的预设或自定义分母实时变化；极大分母时限制绘制密度以保持流畅，实际吸附精度不变。整数拍线旁显示实际节拍编号，数字朝向相机以方便阅读，每 4 拍强调一次。

## 已实现

- 自动扫描本地曲库、封面、音频及实际存在的难度文件；兼容新旧两套元数据命名及 GBK / UTF-8 编码。
- 新建谱面、导入 ZIP 或 YAML、导入音频、封面居中裁剪为 512 × 512 PNG。
- 手部方向 / 颜色 / 地雷、脚部短音符 / 长音符、障碍物、事件属性编辑；阻止放置到两处未使用的内部格。
- 右侧全屏 3D 工作区；左栏为歌曲列表；难度移到 3D 歌曲信息面板，按 Ring / RingDance 分类，工具、时间轴及播放控制作为场景内的子窗口。
- 编辑工具可拖动、收起，双击标题栏复位；时间轴开关位于播放条上方中央，时间轴默认收起，可向上展开、向下隐藏；展开时占用下方空间并缩小 3D 画布，相机比例和拾取同步更新。
- 真正的 3D 空间预览、自由旋转、WASD 平移、按住右键时 Shift / 空格垂直移动、相机远近按钮、居中俯看的一键相机重置。
- 3D 窗口常驻 SNAP 控件，支持 1 beat、1/2、1/3、1/4、1/6、1/8、1/16、1/24、1/32，以及自定义分母（例如输入 5 = 1/5 拍）；同步作用于时间轴、放置与步进。时间轴支持滚动、拖动、框选、多选、按拍数范围选择与删除。
- 撤销重做、复制粘贴、左右／上下／对角镜像；手部红蓝音符混合打组、加入组、取消组，复制时生成新的分组 ID。
- 音频同步播放、波形、0.1×–2× 连续倍速滑杆、歌曲音量、独立节拍器音量、手动点击测 BPM、BPM 和音频偏移设置。
- 歌曲与谱师信息、难度创建、跨难度复制灯光、手脚跳跃速度与出生偏移、书签。
- 字段 / 分组 / 同拍同位置检查，音符数量、平均密度、红蓝比例和层级统计。
- 本地保存、ZIP 导出所有已有难度和歌曲资源；保留未知字段、分组与 `customData`。
- 保存前备份到所选 `Map/.ringmapper-backups/<歌曲目录>/<时间戳>/`；检测所有待覆盖文件的外部变化，包括其他难度、音频和封面。写入失败尝试恢复原文件，恢复失败时提示备份位置。
- 浏览器草稿恢复。草稿只保存 YAML 数据；尚未保存的外部音频和封面需要重新导入。

## 基本操作

1. 从左侧选择歌曲和难度，或点击“新建”/“导入”。新建歌曲可在设置中选择音频和封面。
2. 使用底部进度条、节拍输入框或 3D 内的滚轮定位。直接点击圆环分区或脚部平台即可放置对应音符，无需切换工具；点击已有的同拍音符可选中它。编辑工具分为“音符”“障碍物”“灯光事件”，没有选择／放置／擦除模式；时间轴也可直接点击空位放置。新增音符默认不选中；点击画布空白区域取消选择，点击其他 UI 控件保留选择。数字键 **1 / 2 / 3** 分别切换音符 / 障碍物 / 灯光，输入框内仍正常输入数字。**按住 Shift 时禁止新增**，包括 3D、时间轴与添加按钮；Shift 多选和右键＋Shift 降低相机仍可使用。
3. 点击音符后在悬浮编辑工具中调整属性；与圆环重叠的已有音符可用 Alt＋点击直接选中。3D 内按住 Alt＋左键拖动音符，可在对应的手部或脚部轨道内换位，并吸附到合法位置；保持原节拍、颜色、方向、分组和时长，整段拖动可一次撤销。开始拖动时暂停播放。时间轴中拖动可移动节拍和位置；Shift＋拖动空白处可框选。
4. 在 3D 中按住 `Alt`，鼠标指向脚部音符并滚动滚轮：向上增加、向下减少当前 SNAP 的拍长；短音符加长时自动转为长音符，缩短到 0 拍时自动转为短音符，支持撤销，不移动歌曲进度。触控板的小幅滚动会累积为完整吸附步长。在时间轴中，`Alt` 拖动手部音符更改方向；`Alt` 拖动脚部音符修改持续时间；障碍物不提供持续拍数编辑。
5. 未分组的多个手部音符可打组，允许红蓝混合。选中的音符全部属于已有组时，附近显示“取消组”；选中组内和组外音符时，可新建组或加入已有组。工具窗口不再保留固定“取消组”按钮。取消组会解散所选成员所属的整个组。组首显示圆圈，组员有较弱描边和柔光，选中项仍用更亮的青色描边与勾选标记。双击已有组中的任意音符可快速选中整个组（包含预览范围外的成员）。组头标记为 `1`，组尾标记为 `2`，其余组员保留同一个 `groupId`。
6. 工具窗口提供左右、上下、对角三个带圆环示意图的方形镜像按钮，点击即应用于选中项。“上下”翻转手部层级；“对角”按上下、左右同时翻转。左右／对角反转脚部位置及障碍物位置；上下不移动脚部与障碍物。镜像仅改变位置，所有方式均保留原始颜色与击打方向。所有方式保留节拍、时长、分组和扩展字段，可撤销；障碍物模式仅启用左右镜像。
7. 切换“障碍物”后，地面出现 1–4 四轨入口，此模式只放置障碍物。鼠标可在覆盖圆环与脚部判定区域的四轨大矩形内放置，中央横线上方放上半墙，下方放全高墙；悬停显示低透明度预览。底部 1–4 入口仍可点击。新墙固定 **1 轨宽、0.04 拍**，呈薄片状，不提供宽度和持续拍数输入。原谱的其他宽度和持续拍数仍保留。上半墙 `type: 1` 下部留空，全高墙 `type: 0` 占据完整高度。
8. 音符完全重叠时，音符旁和全局状态栏同时报错；全局提示可列出错误并跳到对应 beat，修改、删除、撤销后实时更新。点击歌曲设置的“测 BPM”会自动开始播放，再按音乐节奏继续点击。
9. 播放试听并运行“检查谱面”，再保存或导出 ZIP。

常用快捷键：`Ctrl+B` 在当前拍新增书签（所有书签常显于歌曲进度条，点击跳转），`Ctrl+F` 左右镜像，`Ctrl+A` 仅选当前类别中处于 3D 视野且未被工具面板遮挡的对象；`Space` 播放，`Ctrl+滚轮` 切换吸附预设，`Ctrl+Z / Y` 撤销 / 重做，`Ctrl+C / V` 复制 / 粘贴，`Ctrl+S` 保存，`Delete` 优先删除选中项，无选中项时删除鼠标指向的对象（支持 3D 和时间轴），`Q` 切换当前放置颜色，左右箭头逐拍移动，`Shift+点击` 多选，中键换色，时间轴右键删除。

歌曲倍速不是 1× 时会显示“↺ 1×”按钮，恢复默认速度时保持播放进度和播放状态。节拍器的基础输出提高为原来的四倍，原音量滑杆范围与默认值保持不变。歌曲名称、艺术家等文本可正常选中并复制为纯文本；Ctrl+C 在选中了页面文字时优先复制文字。

Delete 优先删除已选中的音符、墙体或灯光事件，不受鼠标位置影响；无选中项时删除悬停对象，悬停空白处则不操作。Q 不修改已有音符，也不会拦截输入框中的正常录入。放置颜色可在编辑工具内查看和切换；3D 相机控制区不再显示 Q 按钮。工具窗口的垃圾桶 / Del 按钮用于删除选中项。

3D 视图：**右键拖动旋转**；**滚轮向上前进、向下后退歌曲进度**（编辑设置中的“歌曲进度滚轮反向”可反转并记住偏好），移动幅度随时间轴的吸附细分调整，播放中也能定位。点击预览使其获得焦点后用 **WASD 水平移动相机**。**按住鼠标右键时，Shift 降低、空格升高**；松开右键后空格播放 / 暂停，Ctrl 仅用于编辑快捷键。左上方的 **＋ / −** 按钮拉近 / 拉远相机，定位按钮恢复居中俯看的视角。预览中的右键用于控制相机；删除音符使用 Delete。脚部踏板显示有符号轨道编号，属性面板保留原始编号字段。

吸附下拉栏、工具按钮等操作结束后，键盘焦点会回到 3D 编辑区，空格可直接播放 / 暂停，音符选中状态不会因相机或面板操作丢失。输入框仍可正常录入；在编辑区输入框中按 Enter 可结束录入并回到编辑区。

## 格式与兼容边界

详见 [谱面格式说明](docs/MAP_FORMAT.md)。

- 时间字段以拍为单位；编辑器使用 `音频秒数 = 拍 × 60 / BPM + songTimeOffset`，偏移符号需在游戏中试听对照。
- 支持保留原字段值和未知扩展，写出时按节拍排序。YAML 注释、缩进、字段引号形式不保证保持；保存统一使用 UTF-8。
- 右侧新增真实 3D 灯光轨道：六类灯光加四类速度，绿／黄条表示灯光，绿点及高度填充表示速度 0–6。按 3 进入灯光分类，“灯光总览”定位到全部轨道；点击空位放置、点击事件选择，Alt 拖动移动轨道和节拍，支持复制、删除与撤销。名称与灯光效果采用可校准的样本推定映射，不能保证与官方效果完全一致；未知事件显示为扩展轨道并保留原值。详见 [灯光映射与校准](docs/LIGHTING_MAPPING.md)。
- 3D 预览需要 WebGL 2；浏览器不支持时会明确提示，时间轴仍可编辑。圆环精确角度、脚部编号与障碍物类型的游戏空间语义仍可进一步校准。
- 未接入官方账号 / 云曲库、自动 BPM 检测或音频转码。灯光提供本地示意预览，未复刻官方场景材质和精确时序。点击测 BPM 是人工辅助工具。
- 浏览器可预览 OGG / MP3 / WAV；参考视频要求游戏使用 OGG，本工具不会把 MP3 / WAV 自动转换为 OGG。
- 音符坐标、脚部位置编号的实际空间含义、障碍物类型语义和游戏端运行兼容性仍需实机验证。
- 目前使用固定 BPM。现有样本中的 `customData.BPMChanges` 均为空；非空变速数据会保留，但不会参与播放时间换算。

## 验证

```powershell
npm test
npm run test:ui
npm run build
```

核心测试覆盖时间换算、历史记录、路径边界、圆环映射、新旧元数据、原始 YAML 的语义往返以及全库谱面校验。浏览器测试覆盖真实编辑、播放、ZIP 导入导出、本地资源保存、备份、冲突检测与难度创建，以及 WebGL 渲染、全部 10 个位置拾取、滚轮定位与相机控制、浮动面板与收起时间轴、半透明圆环与无箭头弧形音符、播放纵深变化和脚部长音符，以及直接放置、默认未选中、焦点返回、Alt 拖动与撤销、Shift 放置保护、Q 换色、悬停删除、纵深拉伸、地面拍号和三种镜像。

浏览器测试默认使用已安装的 Chrome；若使用 Playwright 自带 Chromium，可设置 `PLAYWRIGHT_CHANNEL=chromium` 并运行 `npx playwright install chromium`。全库 YAML 往返检查需要约 2–3 分钟。

界面测试将歌曲复制到独立浏览器上下文的 OPFS 测试目录，保存和备份只操作副本，不修改项目 Map。`npm run test:static` 使用独立静态服务器验证构建产物。

圆环填充：选中两个不同节拍的手部音符，点击工具栏“填充”。按时间确定起终点，每步沿十格圆环前进一格并均匀分配节拍，步数满足 `步数 ≡ 有向距离 (mod 10)`。切换顺时针／逆时针、增加／减少密度或直接选择方案，可让路径多绕整圈且准确到达终点。分母由“步数 ÷ 拍数差”计算，不限于 SNAP 预设；场景当前 SNAP 不会被修改。方案理论无限，编辑器枚举最多新增 2048 个音符且分母不超过 1,000,000 的方案。新音符继承起点颜色与击打方向；两端同组时加入原组，已有占位保留且不重复放置。调整只替换本次生成的音符，端点保持选中，支持逐步撤销重做；点击完成、换选区或进行其他谱面修改后结束本次调整。

编辑设置可填写默认纵深（0.25–10，初始 5×）和默认预览范围（1–64，初始 8 拍）。修改后点击完成会应用并在本浏览器保存，刷新后采用保存的默认值；场景滑杆的临时调整不覆盖默认值。

图文入门说明见 [新手教程](docs/BEGINNER_GUIDE.md)，或点击界面右上角“? 新手教程”。难度区展示空档的灰色 ＋ 创建入口；WORKSPACE 旁可选择本地 Map 文件夹、重新授权和刷新曲库。设置支持手部和脚部音符不透明度的独立／同步调整，偏好在本浏览器保存。音符类别可直接选中墙体。音符旁同时提供打组与填充快捷入口；填充面板的“取消”完整恢复本次填充前的谱面和历史记录。
